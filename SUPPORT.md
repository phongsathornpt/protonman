# Support

Use GitHub Issues for reproducible bugs and feature requests. Before opening an issue, check existing issues and the documentation under `docs/`.

For usage questions, include the Protonman version, operating system and architecture, execution mode (TUI, headless, or ACP), provider/model when relevant, permission mode, sandbox profile, reproduction steps, and sanitized logs.

Do not include API keys, access tokens, credentials, or other secrets. Security vulnerabilities must be reported privately as described in `SECURITY.md`.
